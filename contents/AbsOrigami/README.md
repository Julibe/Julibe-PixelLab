# AbsOrigami | An Universe in Paper

A Pen created on CodePen.

Original URL: [https://codepen.io/Julibe/pen/qENzNrR](https://codepen.io/Julibe/pen/qENzNrR).


AbsOrigami is a gamified web application concept that blends the delicate art of origami with a robust, "Bento-style" user interface. Designed to feel like a premium digital paper kit, the app features textured backgrounds, squircle aesthetics, and smooth transitions to guide users from "White Belt" to "Eternal Folder."

### How to use

1.  **Explore the Bento:** Navigate the dashboard grid to see your stats, daily specials, and quick picks.
    
2.  **Start an Adventure:** Click the "Adventure" tab to filter challenges by difficulty (Easy to Hard).
    
3.  **Complete a Quest:** Click any available tile to open the Quest Modal. Step through the instructions and click "Finish" to earn XP.
    
4.  **Level Up:** Gain XP to unlock new belt colors and watch the progress bar animate.
    
5.  **Check the Community:** Visit the leaderboard to see where you rank among global folders.
    

### Technical Highlights

-   **Bento Grid Layout:** A responsive, modular grid system using CSS Grid for the dashboard.
    
-   **Paper Textures:** Subtle CSS gradients and patterns create a tactile paper feel.
    
-   **Gamification Engine:** A lightweight JavaScript state management system tracks XP, levels, and unlocked achievements.
    
-   **Squircle Design:** Modern `corner-shape: squircle` properties (with fallback border-radius) for organic UI elements.
    
-   **GSAP Animations:** Smooth entrance sequences and modal interactions.
