Hey there! Welcome to the **Analytics Dashboard Graphs**, a sleek and responsive dashboard concept that brings data to life with fluid animations.

This project demonstrates how to build a modern UI without heavy chart libraries. Instead, it uses **raw SVG generation** paired with the robust **[GreenSock Animation Platform (GSAP)](https://greensock.com)** for high-performance animations. The layout is built on a responsive CSS Grid that adapts gracefully from desktop to mobile, while the visual style utilizes a "Deep Forest & Lime" color palette for high contrast and readability.

### Key Features
*   **Dynamic SVG Charts:** Line, Bar, Area, and Gauge charts generated on the fly via JavaScript.
*   **GSAP Powered:** Smooth entry animations and real-time data updates powered by [GSAP](https://greensock.com).
*   **Modern CSS:** Utilizes CSS variables and native CSS nesting for clean, maintainable stylesheets.
*   **Responsive Design:** A flexbox sidebar and grid-based main content area that stack perfectly on smaller screens.
