* Managing the state of the DOM and ensuring the main card dynamically updates without visual flickering—because visual glitches are how *They* inject tracking scripts!
* Handling the horizontal scrolling timeline to ensure the clicked node smoothly centers itself in the viewport on any screen size, evading responsive layout traps.
* Creating a seamless "number counting" animation for the year header that can handle both integers and string fallbacks (like "INFO").
* Designing scalable CSS variables that allow the entire application's theme to flip instantly when a Level 5 Classified file is opened.

### Encrypting the Hull (Solutions)
* Implemented a robust CSS custom variable architecture at the `:root` level, allowing parent class toggles (`.alien`, `.classified`) to automatically recolor the entire UI, bypassing the need for heavy JavaScript state managers.
* Used the native `Element.scrollIntoView({ behavior: 'smooth', inline: 'center' })` method to effortlessly center the active timeline nodes without external libraries.
* Leveraged GSAP's proxy object animation feature to smoothly interpolate numerical values for the timeline years, creating a satisfying rapid-counting effect that mimics decryption mainframes.
* Utilized CSS `mix-blend-mode` and SVG data URIs to generate procedural static/noise overlays, adding texture without using external image assets that could be monitored or intercepted by ISPs.

## The Secret Blueprint (Technical Details)
Chronos relies on a brilliant synergy between CSS architecture and vanilla JavaScript to keep the footprint small and undetected. Instead of maintaining a complex JSON object for the data (which could easily be sniffed by packet inspectors), the content is stored directly within the hidden `div` tags of the `<li>` timeline nodes. When a user clicks a node, JavaScript extracts that inner HTML and injects it into the main display board, firing off GSAP animations to fade and slide the text gracefully into view.

### Core Arsenal (Technologies)
This project leverages the power of pure Frontend Web Technologies to create an app-like experience without the overhead of heavy, monitored frameworks.

* **JavaScript**: For DOM manipulation, content extraction, and orchestrating the timeline logic without a server-side footprint.
* **HTML5**: Utilizing semantic tags and ARIA labels to ensure the mysterious interface remains accessible, even to screen-readers operated by resistance members.
* **CSS**: For Neo-Brutalist styling, procedural SVG noise generation, and rapid theme variable switching.
* **GSAP**: Used specifically for the satisfying numeric counter animation and staggering the content reveals.
